## m2us v0.1.0

US配列のMacBook（Apple Silicon）で、左右のCommandキーの空打ち（単体タップ）を「英数 / かな」に割り当てる超軽量デーモン **m2us** の初回リリースです。

### 主な機能・特徴

- **左右Commandキーの空打ち切り替え**
  - 左Command単体タップ → **英数** (`kVK_JIS_Eisu`)
  - 右Command単体タップ → **かな** (`kVK_JIS_Kana`)
  - 他キーとの同時押し（`Cmd + C` 等）やマウス操作（`Cmd + Click` 等）時は通常のCommandキーとして動作します。
- **極限までの軽量・低遅延設計**
  - **外部クレート依存ゼロ**: macOSの `CoreGraphics` / `CoreFoundation` を最小限のFFIで直接呼び出し、数十KB台の単一バイナリを実現。
  - **アイドル時CPU使用率 0%**: ポーリングを一切行わない完全イベント駆動（`CGEventTap` + `CFRunLoop`）。
  - **タイピング遅延ゼロ**: 監視専用モード（`ListenOnly`）と最高優先度スレッド（`QOS_CLASS_USER_INTERACTIVE`）の採用により、通常入力への遅延が発生しません。

### 動作環境

- macOS（Apple Silicon / `aarch64-apple-darwin` 専用）

### インストール・利用手順

1. Release Assets から `m2us.tar.gz` をダウンロードして展開し、パスの通ったディレクトリへ配置します：
   ```bash
   tar -xzf m2us.tar.gz
   xattr -d com.apple.quarantine m2us 2>/dev/null || true
   mkdir -p ~/.local/bin
   mv m2us ~/.local/bin/
   ```
2. **システム設定 > プライバシーとセキュリティ > 入力監視（またはアクセシビリティ）** に `~/.local/bin/m2us` を追加して許可します。
3. 自動起動（LaunchAgent）の設定方法は `README.md` を参照してください。
