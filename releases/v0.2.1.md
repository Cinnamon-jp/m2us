## m2us v0.2.1

US配列のMacBook（Apple Silicon）向け超軽量キーリマップデーモン **m2us** の v0.2.1 リリースです。
`hidutil` によるCapsLockリマップの扱いを中心に、運用上の不具合を修正するバグ修正リリースです。キーマップの機能自体に変更はありません。

### 修正点

- **既存のキーリマップを保持するように修正**
  - 従来は起動時に `UserKeyMapping` を丸ごと置き換え、終了時に全消去していたため、ユーザーが別途設定していたリマップ（Ctrl↔Caps 等）が失われていました。
  - 起動時に現在の設定を読み取って CapsLock→F18 だけを追加し、終了時は元の設定へ書き戻します。
  - 現在の設定を読み取れなかった場合は警告を出力し、従来どおりの動作になります。
- **異常終了後に CapsLock が無反応になる問題を修正**
  - `SIGHUP`（ターミナルを閉じた場合など）でも元の設定へ復元します。
  - panic で終了する場合も、abort の前に元の設定へ復元します。
  - 前回異常終了してリマップが残っていても、再起動すると自動的に正常な状態へ戻ります。
  - `SIGKILL` で終了した場合は復元できません。この場合は再起動するか、LaunchAgent の自動再起動を待ってください。
- **二重起動を防止**
  - すでに m2us が動作している場合は、何も変更せずにエラーで終了します。
  - 従来は、二重起動したプロセスの一方が終了するとリマップが全消去され、もう一方が動いていても CapsLock が使えなくなっていました。

### 動作環境

- macOS（Apple Silicon / `aarch64-apple-darwin` 専用）

### インストール・利用手順

1. Release Assets から `m2us.tar.gz` をダウンロードして展開し、パスの通ったディレクトリへ配置します：
   ```bash
   tar -xzf m2us.tar.gz
   xattr -d com.apple.quarantine m2us 2>/dev/null || true
   mkdir -p ~/.local/bin
   mv m2us ~/.local/bin/
   ```
2. **システム設定 > プライバシーとセキュリティ > 入力監視（またはアクセシビリティ）** に `~/.local/bin/m2us` を追加して許可します。
3. 自動起動（LaunchAgent）の設定方法は `README.md` を参照してください。

### v0.2.0 からのアップデート

- 動作中の m2us を停止してから、バイナリを置き換えて再起動してください（LaunchAgent を使っている場合は `launchctl unload` → 置き換え → `launchctl load`）。
