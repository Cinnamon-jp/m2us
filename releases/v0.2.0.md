## m2us v0.2.0

US配列のMacBook（Apple Silicon）向け超軽量キーリマップデーモン **m2us** の v0.2.0 リリースです。
本バージョンでは、従来の左右Commandキーによる「英数 / かな」切り替えに加え、**CapsLockキーの「単押し＝Esc / 長押し＝CapsLock」機能**を追加しました。

### 新機能・変更点

- **CapsLockキーの単押し・長押し割り当て**
  - **CapsLock単押し（250ms未満でリリース）** → **Esc** (`kVK_Escape`: `0x35`) を送出
  - **CapsLock長押し（250ms以上ホールド）** → **250ms経過した瞬間にCapsLock状態をトグル**
  - 押下から250ms経過するまでの間に他のキー・修飾キー・マウスクリック・スクロールが発生した場合は単押し（Esc）をキャンセルします。
  - 起動時に `hidutil` で物理CapsLockのハードウェア遅延を無効化（`CapsLockDelayOverride: 0`）してリマップし、終了時（`SIGINT` / `SIGTERM`）に自動復元します。
- **CapsLock ON時の左右Command単押し対応**
  - CapsLockがON（大文字ロック中）の状態でも、左右Commandキーの単体タップによる「英数 / かな」切り替えが動作するように改善しました。

### 動作環境

- macOS（Apple Silicon / `aarch64-apple-darwin` 専用）

### インストール・利用手順

1. Release Assets から `m2us.tar.gz` をダウンロードして展開し、パスの通ったディレクトリへ配置します：
   ```bash
   tar -xzf m2us.tar.gz
   xattr -d com.apple.quarantine m2us 2>/dev/null || true
   mkdir -p ~/.local/bin
   mv m2us ~/.local/bin/
   ```
2. **システム設定 > プライバシーとセキュリティ > 入力監視（またはアクセシビリティ）** に `~/.local/bin/m2us` を追加して許可します。
3. 自動起動（LaunchAgent）の設定方法は `README.md` を参照してください。
