## m2us v0.3.0

US配列のMacBook（Apple Silicon）向け超軽量キーリマップデーモン **m2us** の v0.3.0 リリースです。
本バージョンでは、左右Commandキー単体タップ時の「英数 / かな」送出を**テキスト入力フォーカス時のみに限定**し、非テキスト入力時は純粋なCommandキーとして動作するように改善しました。

### 新機能・変更点

- **テキスト入力フォーカス時限定の「英数 / かな」発火**
  - Accessibility API（`AXUIElement`）およびプロセス情報を用いて、現在フォーカスされているUI要素がテキスト入力を受け付けている場合（テキスト入力欄、エディタ、ターミナル、Electronアプリ等）のみ `英数` (`0x66`) / `かな` (`0x68`) を送出します。
  - **非テキスト入力時のCommand単体ショートカットとの共存**: Finderでのファイル操作中やブラウザでのWebページ閲覧中など、文字入力を行っていない場面では「英数 / かな」を送出せずネイティブのCommandキーイベントのみを通過させるため、Commandキーの単押し・2連打・長押し等をトリガーとするランチャーやユーティリティと競合せず、不要なIME切り替えも発生しません。
  - ※テキスト入力欄にフォーカスがある状態では従来どおり「英数 / かな」が送出されるため、テキスト入力中はCommand単体ショートカットとの競合が引き続き発生します。
- **フェイルセーフ設計（「迷ったら送る」）と低遅延・フリーズ耐性**
  - 常時監視やポーリングは一切行わず、左右Commandの単体タップ解放時のみ判定を実行します（アイドル時CPU使用率 0%・通常キー入力時の遅延ゼロを維持）。
  - 個別IPCタイムアウト（10ms）・IPC回数上限（最大4回）・新規IPC開始期限（30ms / 最悪40ms）を設け、フォーカス先アプリの高負荷・応答不能（タイムアウト）時やアクセシビリティ権限未付与・未知のエラー発生時は、即座に**従来動作（英数 / かなを送出する）**へフォールバックします。
  - 外部プロセスへの属性書き込み（`AXManualAccessibility` 等）は一切行わず、対象アプリのメモリ増加やVS Code等のスクリーンリーダー最適化モード誤作動を起こしません。
- **CapsLock（単押し＝Esc / 長押し＝CapsLock）は従来どおり常時有効**
  - `Esc` は非テキスト入力時（モーダル解除・ダイアログを閉じる等）にも必須であるため、テキスト入力判定の対象外として常時発火します。

### 動作環境

- macOS（Apple Silicon / `aarch64-apple-darwin` 専用）

### インストール・利用手順

1. Release Assets から `m2us.tar.gz` をダウンロードして展開し、パスの通ったディレクトリへ配置します：
   ```bash
   tar -xzf m2us.tar.gz
   xattr -d com.apple.quarantine m2us 2>/dev/null || true
   mkdir -p ~/.local/bin
   mv m2us ~/.local/bin/
   ```
2. **システム設定 > プライバシーとセキュリティ > 入力監視** および **アクセシビリティ** の両方に `~/.local/bin/m2us` を追加して許可します。
3. 自動起動（LaunchAgent）の設定方法は `README.md` を参照してください。

### v0.2.x からのアップデート

1. 動作中の `m2us` を停止（`launchctl unload ~/Library/LaunchAgents/com.user.m2us.plist`）してからバイナリを置き換えてください。
2. バイナリ更新後はコード署名の識別子が変化するため、**システム設定 > プライバシーとセキュリティ** の **「入力監視」** と **「アクセシビリティ」** の両方から既存の `m2us` を一度 `-` で削除し、`+` で再追加してから `launchctl load ~/Library/LaunchAgents/com.user.m2us.plist` で起動してください。
